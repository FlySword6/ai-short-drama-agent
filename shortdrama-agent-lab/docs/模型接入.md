# 本机模型接入

范围：2026-09-30 确认并实现的最小 NestJS＋Fastify 模型后端。它提供文本及图片理解，不生成图片、视频或声音，不是完整预算账本或生产调度器。2026-10-01 起「真实项目」页面的事实与分镜 Agent 已经复用此本机文本模型通道；网页设置页仍未接入模型配置。详见[首个里程碑实现](首个里程碑实现.md)。

## 启动

需要 Node.js >=22.16，以及已经配置好的本机 Codewiz 代理。项目根目录的 `.env` 已配置；新检出时从 `.env.example` 复制一份为 `.env`，不要覆盖已有配置。

在项目根目录运行：

```sh
npm ci --ignore-scripts
npm run dev
```

`dev` 先编译再启动（无热重载）。修改 TS 后重跑；仅改 `.env` 时重启 `npm start`。后端仅监听 `127.0.0.1:8788`，代理为 `127.0.0.1:8787`；本项目不会启动、重配或替换代理。

```sh
curl http://127.0.0.1:8788/healthz
curl http://127.0.0.1:8787/healthz
npm run models:list
```

以上检查不调用模型、不消耗模型额度。健康响应仅代表进程可访问，不证明公司 SSO、额度或所有模型可用。公司密钥与 SSO 由现有代理管理，不复制到本项目；无需填写假的 OpenAI API key。使用时仍须具备公司网络、有效登录及模型权限。

## 环境变量

| 变量 | 当前配置 | 含义 |
|---|---|---|
| PORT | 8788 | 新后端端口，仅本机可访问，不能与代理同端口。 |
| LLM_BASE_URL | http://127.0.0.1:8787/v1 | 已有代理的地址，本版本拒绝远程地址与带凭据 URL。 |
| LLM_DEFAULT_MODEL | gpt-5.6-terra | 默认模型条目。 |
| LLM_REASONING_EFFORT | medium | 默认 `gpt-5.6-terra` 使用 `medium`，避免首轮拆解无意使用其代理配置中的 `max`；若填具体档位，仅对默认模型生效；请求参数可覆盖。 |
| LLM_MAX_OUTPUT_TOKENS | 8192 | 一次输出预算（可能包含不可见推理），允许 256–32768；不等于上下文窗口。 |
| LLM_TIMEOUT_MS | 180000 | 本机请求等待上限，允许 1000–600000 毫秒。超时不代表远端取消或免费。 |
| LLM_MAX_CONCURRENT_CALLS | 2 | 同进程并发上限，超出立即拒绝，不排队或自动重试。 |

启动读取 `.env`，已有进程环境变量优先。`.env` 已被 Git 忽略，本机权限为 600；可提交的 `.env.example` 不含密钥。变量不得改成 `VITE_` 前缀，不把公司凭据交给浏览器。

## 使用示例

保持后端在另一个终端运行。以下调用会消耗公司模型额度；每条命令仅提交一次请求：

```sh
npm run models:text -- "请用一句话解释什么是连续镜头" --allow-paid
npm run models:text -- "请概括这段测试文本" claude-sonnet-5 --allow-paid
npm run models:image -- ./examples/my-image.png "图中有哪些物体？" gpt-5.6-terra --allow-paid
```

图片示例中的文件由你提供，不存在时不会调用模型。脚本读取指定图片并以内嵌 Base64 发送，不上传整个项目。只接受 PNG/JPEG/WebP，每图最多 5 MiB、每请求最多 4 图、总请求最多 10 MiB。后端不读取调用者提供的文件路径，也不抓取任意图片 URL；图片魔数仅做基本格式核对，不代替完整图片解码校验。

HTTP 接口：

```sh
curl http://127.0.0.1:8788/api/model-calls \
  -H 'Content-Type: application/json' \
  -H 'X-Shortdrama-Call: 1' \
  -d '{"model":"gpt-5.6-terra","messages":[{"role":"user","content":"17+25等于多少？"}],"reasoningEffort":"low","maxOutputTokens":4096,"allowPaid":true}'
```

- `GET /api/models`：默认模型、14 个条目、图片能力与可选推理档位。
- `POST /api/model-calls`：`messages` 必填，`model`、`reasoningEffort`、`maxOutputTokens` 可选；`allowPaid:true` 和请求头必须显式提供。
- 消息支持 `system/user/assistant` 文本，多模态数组只允许在 `user` 消息内。
- 图片片段形如 `{ "type":"image_url", "image_url":{ "url":"data:image/png;base64,..." } }`；同一数组可含 `{ "type":"text", "text":"描述图片" }`。
- 响应含 `text`、`requestedModel`、`reportedModel`、`status`、`finishReason`、`usage`、`durationMs`。请求和响应的模型名称不证明底层权重身份。
- `status:incomplete` 表示输出被截断，不能当成完整成功。空输出明确报错，不自动增加额度续写。
- 本版只提供非流式文本结果，未暴露模型工具循环、结构化输出约束、内部推理过程或自动上下文压缩；这些不能因为代理可能支持就当成本项目已实现。

项目内部也可以直接复用编译后的独立适配器，不必经 HTTP：

```js
const { readConfig } = require('./dist/config');
const { ModelClient } = require('./dist/models/client');
const client = new ModelClient(readConfig()); // 宿主进程先加载 .env
// 以下操作会消耗额度，由上层确认后调用：
client.call({
  model: 'gpt-5.6-terra',
  messages: [{ role: 'user', content: '测试问题' }],
  reasoningEffort: 'low', maxOutputTokens: 4096, allowPaid: true,
}).then(console.log).catch(console.error);
```

TS 入口在 `src/models/client.ts`；契约与 Ajv 校验在 `src/models/contracts.ts`。Controller 通过自定义 Pipe 校验，Service 协调调用，独立适配器不依赖 HTTP 请求。直接调用同样执行参数、图片、并发与超时限制。没有接入正式 Run/Task，不会写入剧情或制作计划。

* Luna 既往图片测试曾被上游资源策略拒绝，本次未重测。Gemini Pro 的两项是不同推理预设，不是两套独立模型。所有窗口数字仅沿用配置，不是本次验证的硬上限，也不保证长文本准确性；本后端不做模型专属 token 计数，实际超窗由上游拒绝，不截断输入冒充成功。

不发送 `ultra`：它不是这个代理的有效原生推理档位。提高推理强度可能耗尽输出预算并延迟回答。项目默认模型 `gpt-5.6-terra` 设为 `medium`；显式选择其他模型时仍沿用其注册表默认档位，除非请求单独覆盖。本次小样测试主动使用 `low`＋4096 输出预算，并不验证其他档位质量。

## 失败与安全边界

错误使用 `error.code` 定位：`IMAGE_UNSUPPORTED`、`EFFORT_UNSUPPORTED`、`UNKNOWN_MODEL`、`LOCAL_BUSY` 是本地拒绝；`UPSTREAM_ERROR` 带上游 HTTP 状态但不反射原始响应；`PROXY_UNAVAILABLE`、`UPSTREAM_TIMEOUT` 需要检查代理、网络、登录或人工核对。403/429 可能分别对应权限/资源或额度/限流，不能靠换密钥绕过。

不自动重试、不自动切模型。超时和响应丢失可能已经计费，手动重试前先核对。不记录提示词、图片、原始供应商响应、凭据或内部推理；返回文本与数字用量供调用方使用。用量不等于费用：价格、费用预留/结算、跨进程预算和持久调用账本尚未实现，不能把 `allowPaid` 当成金额上限或完整预算控制。

当前仅供本人在这台机器上使用。没有远程访问认证；拒绝浏览器 Origin、非回环 Host，并要求脚本请求头。该措施不是多用户安全系统，不能暴露公网、做端口转发或部署到共享服务器。进程退出不持久保存模型响应，也不能保证取消已经发到公司的请求。

## 验证

```sh
npm test
npm run build
# 仅在明确接受两次额度消耗、且后端已启动时运行：
npm run models:smoke -- --allow-paid
```

普通测试只用 mock／本机临时 HTTP 服务，不调用公司模型。smoke 固定最多两次请求：合成算术文本和程序生成的红色 PNG，只测试 GPT-5.6 Terra；不会发送项目代码、剧本或用户图片，不会失败后自动补测。重跑 smoke 也会再次消耗额度。实测结果见 [模型接入验证](模型接入验证.md)。

实现依据：[NestJS 自定义 Pipe](https://docs.nestjs.com/pipes)；图片片段采用 [OpenAI 图片输入格式](https://developers.openai.com/api/docs/guides/images-vision)，实际跨供应商转换由现有本机代理负责。官方接口说明不能证明公司路由的实时可用性。
