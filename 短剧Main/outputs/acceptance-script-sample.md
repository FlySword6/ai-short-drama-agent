# 验收用样例剧本(周六走查 / 周一真人验收共用)

> 立于 2026-08-06。**不要现场临时找剧本**——随便一段可能触发不了要验的东西。
> 这一段是照着 `goal-monday-20260810.md` 的硬门倒着设计的,每个元素都有用处。

---

## 为什么是这一段(设计意图,别改坏了)

| 硬门 | 这段剧本里对应什么 |
|---|---|
| **G6 资产真入库** | 角色 3 个、场景 2 个、道具 3 个,类型齐全,拆解应该都能认出来 |
| **G6 同名角色只有一条** | **陈默在三个镜头里都出现**,拆解不能给他建三条资产 |
| **G13 跨镜一致** | 陈默连续出现在镜头 1、2、4——**这就是"同一个角色长得一样"的检验对象** |
| **G9 批量生成 ≥3 镜** | 正好 5 个镜头,一次批量提交 |
| **G7 图片出竖屏** | 内容是竖屏短剧的典型构图(近景、人物为主),出横屏会很明显 |
| **G3 风格进提示词** | 配合项目风格设定使用(建项目时填含特征词的风格描述) |

**长度刻意控制在 5 个镜头**:goal 定的是"一个完整片段",不是一整集。太长会让批量生成的钱和时间失控。

---

## 剧本正文(复制这一段粘进平台)

```
第 3 集 · 第 7 场 · 天台对峙

时间:夜
地点:老城区废弃写字楼天台

【镜头 1】
陈默独自站在天台边缘,手里攥着一枚褪色的铜制打火机。远处霓虹灯牌明明灭灭,
照在他半边脸上。他低头看着打火机,拇指反复摩挲上面刻的字。

【镜头 2】
身后铁门被推开。林雪快步走出来,黑色风衣被风吹得贴在身上。她停在三步远的
地方,没有再靠近。

林雪:你答应过我,不再碰这件事。

【镜头 3】
特写:那枚铜制打火机。刻字清晰可见——"给阿默,爸"。打火机边缘有明显磕碰
痕迹。

【镜头 4】
陈默转过身。他脸上没有表情,眼神却很沉。风把他额前的头发吹乱。

陈默:那你告诉我,他那天晚上到底见了谁。

【镜头 5】
天台另一侧,老周靠在水塔的阴影里,手里的烟头明灭了一下。他看着对峙的两人,
慢慢把一部老式翻盖手机收进口袋。
```

---

## 拆解之后应该看到什么(这就是 G6 的判据清单)

**角色(3 个)**

| 角色 | 出现在哪几个镜头 | 检查什么 |
|---|---|---|
| **陈默** | 1、2(背身)、4 | **必须只有一条资产**,不许因为出现三次就建三条 |
| 林雪 | 2 | 黑色风衣是她的外形特征,应该被记下来 |
| 老周 | 5 | 配角,也该被认出来 |

**场景(2 个)**:天台(主场景)、水塔阴影处(同一场景内的位置,**认成一个还是两个都可接受**,但要能说清)

**道具(3 个)**:铜制打火机(**关键道具,镜头 3 是它的特写**)、老式翻盖手机、烟头

## 走查时按这个顺序验

1. 建项目,画幅选 **9:16 竖屏**,风格描述里塞一个特征词(建议用 `__STYLEMARK__` 这种绝不会自然出现的串)
2. 粘上面那段剧本 → 拆解 → 确认
3. **去资产库查**:陈默/林雪/老周/天台/打火机 在不在,**陈默是不是只有一条** ← G6
4. 挑镜头 1、2、4(都有陈默)批量生图 ← G9
5. 下载一张,**看尺寸是不是高 > 宽** ← G7
6. 查任一张图的生成记录,**提示词里有没有那个特征词** ← G3
7. 看镜头 1、2、4 三张图,**陈默引用的是不是同一条资产,肉眼看是不是同一个人** ← G13
8. 每镜挑一张点「选用」← G10
9. 拿定稿生视频 → 下载 ← G11 G12

## 一条提醒

**这段剧本不要改**。改了之后上面那张"应该看到什么"的清单就对不上,验收时就没法判"拆解漏了"还是"剧本里本来就没有"。要换剧本,连清单一起换。
