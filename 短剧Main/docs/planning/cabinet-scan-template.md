# 内阁扫描表模板(每工作日一份)

> 2026-08-10 立,拍板出处 `outputs/goal-org-reform-20260810.md` §四。机制说明见 `delivery-workflow.md`「二、三机制」。
> 用法:复制本模板为工作区根 `outputs/cabinet-scans/scan-YYYYMMDD.md`,由文书情报线(或当值采集代理)填写,交秘书长审。
> **七节一节不许删;没有内容的节写「无」。** 空格交不上去——「没发现问题」和「没去看」在表上必须是两个样子。
> 秘书长审表动作:④节当轮裁决并回写 `verdict-log.md`;⑤节转 DC 工单;抽查在③节抽(规程见 `fable-handover.md`「秘书长模式」)。

```markdown
# 内阁扫描表 YYYY-MM-DD

填表:<线名/会话>  审表:<秘书长会话标识>

## ① 本轮新发现问题

每条:问题一句话 + 落卡号。**没落卡的必须写原因**(写不出原因=不作为,当场补卡)。

| 问题 | 落卡号 | 未落卡原因 |
|---|---|---|
| | | |

无则写:无。

## ② 在途单状态表

| 单 | 线 | 最后活动(时刻+证据命令) | 卡点 |
|---|---|---|---|
| | | | |

判活凭证据不凭记忆:git log / 注入 log mtime / 会话文件 mtime,写命令输出关键行。

## ③ 已交付验收结论

**每包必填复验人;复验人与施工人相同=无效行,该包不算已交付。**

| 包/卡 | 施工 | 复验人 | 证据位置(测试数字/读回/截图路径) |
|---|---|---|---|
| | | | |

无则写:无。

## ④ 待 Fable 裁决项(条子)

按 `delivery-workflow.md`「五、条子格式」逐张附上:议题一句话/证据(命令输出或文件路径,不收纯转述)/影响面/互斥选项/拟票建议。

无则写:无。

## ⑤ 待 DC 项

选择题格式,每件:背景一句 + 要什么 + 选项(真互斥,带推荐)+ 卡着谁。

无则写:无。

## ⑥ 额度与成本水位

| 项 | 读数 |
|---|---|
| fable额度: NN% | (DC 用量面板读数,周一起累计占比) |
| 各工人通道水位 | kimi / codex / pi+公司网关 各一句 |
| 当日真金消耗 | ¥N(火山/供应商实扣,来源命令或账单页) |

## ⑦ 体系异常

线死亡、门禁失效、通道断、收件漏扫——**没有异常必须写「无」**,空着=没查。
```

## 填表判据(防糊弄)

- ①节的「落卡号」查得到:看板/issue 上真有这张卡,编号对得上;
- ②节每行有命令证据,禁止「应该还在跑」;
- ③节复验人栏空着或与施工人相同,该行无效;
- ⑥节读数写「未取到」时要写原因(面板没读数/命令失败),不许留空;
- 交表时刻:每工作日收工前;当日无任何活动也要交(七节全「无」的表本身就是「今天全线停摆」的信号)。
