# CONTEXT — 领域词汇表

> 本文件只是词汇表:领域术语的唯一口径。不放实现细节、不当 spec、不当便签。
> 冲突处理:代码或对话里的用法与本表冲突时,以本表为准或当场改本表。

## 创作空间

- **画布(Canvas)**:节点式自由创作空间。节点可以是文本、生成任务、资产引用;节点间连线表达数据流。画布是**通用底座**——自由度最高、上手门槛也最高的创作形态。(DC 2026-07-28 定调)
- **流水线(Pipeline)**:「项目→集→分镜→媒体」的结构化生产流程,即现有工作台。概念上,**流水线是画布的一个预制模板(a workflow)**——我们替用户搭好的简易版,低上手难度。(DC 2026-07-28 定调)
- **单向打开(Pipeline → Canvas)**:流水线可以「打开为画布」(结构化数据投影成画布节点);**画布不能转回流水线**。方向永远是 Pipeline → Canvas,没有反向转换。(DC 2026-07-28 定调;打开后的数据语义——引用还是副本——见 ADR,待定)
