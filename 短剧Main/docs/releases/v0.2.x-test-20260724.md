(自动段服务端编译+人工补充段)、混合检索全站单框、模型能力档(参数
即数据)、选题雷达(52api 未配置时安全停摆)。
**协作与运营**:团队/成员/审批、用户目录选人、成本记账、邀请码注册。
**今日修复批**(dev 分支):隐式首帧根除+提交模式互斥校验、参考图预检、
「已保存」频闪、转参考资产类型与串台、参考栏条目级任务卡(状态/预览/
失败人话/就绪联动)、导演台按钮重叠。
