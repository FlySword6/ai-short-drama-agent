## 1. 目标

在不 push、不部署、不触发付费调用、不直接改云数据的前提下，完成五个可独立交给 Fable 集成验收的工作包：

1. 把生产部署合同从单 ECS + Docker Compose 修订为 VKE + VCI + 云 RDS。
2. 明确并统一云 RDS、TOS、Milvus 与本地开发库的数据真源和迁移次序。
3. 接管 `pi-http-wrapper`，使它具备平台业务工具接入、skill 管理、多 token 认证、审计和 systemd 部署能力；随后接入主产品 assistant。
4. 修复架构自省发现的产物审核、并发冲突测试和统计口径问题。
5. 补齐通用资产复制和轻量行为事件后端。

终点不是“文件存在”，而是每个工作包都有独立 feature 分支、提交、测试证据、回执和明确的未验证项，Fable 可以按提交直接集成。

## 2. 固定边界

- PostgreSQL 是业务与审计唯一正式事实源；Milvus 仅是可重建检索投影；TOS 保存媒体文件。
- 生产数据库使用云 RDS 私网连接；Docker PostgreSQL 只用于开发和测试。
- VKE 使用独立 namespace，不与现有 dev 线 18 个实例混布。
- 生成图片、视频、音频仍是人工一次点击创建一次任务；任何 Agent 或远程 runtime 不得自动代点、批量扩张或自动重试付费动作。
- 密钥只来自环境变量或火山凭据管理，不得写入代码、文档、日志、截图或 git。
- Sol 和子代理不写 `integration/v011`，不自行合并，不 push，不部署，不购买资源，不执行云数据库写入，不调用付费模型。
- Fable 是 `integration/v011` 唯一集成人，并负责最终四件套与集成验收。

## 3. 工作包与完成门

### P0 · VKE 部署修订

交付分支：`feature/v011-vke-release`

必须交付：

- `deploy/k8s/`：独立 Namespace、应用 Deployment、Service、Ingress。

- Compose 的只读根文件系统、能力收缩和非 root 语义映射到 `securityContext`。
- 按 VCI 计费特点给出保守的 CPU/内存 requests/limits，并说明扩缩容边界。
- initContainer 从凭据 `shortdrama/v011/production` 获取配置并写入共享只读 volume；应用容器不包含云访问凭据。
- 持续交付控制台操作说明达到可逐项点击的粒度：GitHub `integration/v011` → `npm ci && npm test` → CR `shortdrama-prod` → 独立 namespace 部署。
- 健康探针、滚动升级、回滚锚点、镜像提交标识和 namespace 隔离均有静态检查。

完成证据：manifest 可渲染、secret 不落盘进仓、相关测试通过、四件套通过、回执存在。

强制检查点：方案和只读证据先交 Fable；Fable 未批准前停止，不执行 migration、不写 RDS、不删除或重建 Milvus。

### P2 · Pi wrapper 接管与产品侧对接

Wrapper 交付分支：`zhongwen-shortdrama-agent:feature/v011-pi-http-wrapper`

第一步必须先收编远端 `/root/pi-http-wrapper/{server.py,client.py,pi-chat.py}`：

- SSH 凭据只通过 DC 安全提供，不写入聊天、仓库或回执。
- 首次提交说明来源路径、原作者/维护者和“原样收编”边界，保留作者归属；功能改造从后续提交开始。
- 若尚无凭据，先完成目标目录、合同、测试骨架和安全接收脚本，状态标为 `awaiting_source`，不得伪造原始代码。

Wrapper 改造完成门：

1. `/pi/prompt/sync` 与 `/prompt` SSE 支持 `system`、外部 `tools` schema，以及 `toolResult` 回传后续推理。
2. skill 管理端点可列出、启用、禁用 `~/.agents/skills` 和 `~/.workbuddy/skills`，路径有 allowlist，操作有审计。
3. Bearer token 只从环境读取，支持多 token、撤销/轮换和审计；废除 `.api_key` 明文单 token。
4. 提供 systemd unit、安装/升级/回滚脚本和不泄密日志策略。

第二步才修改主仓 assistant：

- 远程 provider 转发会话；业务工具仍在主仓执行。
- 远程生成意图只返回待确认草稿，不可创建付费任务。
- 工具结果写入 `agent_message_audit`，再以 `toolResult` 续推理。
- 远程不可用时降级现有 Ark 直连。
- `PI_REMOTE_API_TOKEN` 只走 env；回执提醒 DC 安排旧 token 轮换。

- P2/P3/P4 各自提交、测试、回执完整。
- Fable 可 cherry-pick；Sol 不自行合并。

### 立即停止并汇报

- 需要 push、部署、购买、云资源写入、付费调用或生产 secret 变更。
- 需要删除或覆盖未提交工作。
- 发现现有生产数据与盘点方案预期不一致。
- 远程 wrapper 来源或作者无法确认。
