## 同期定的层级词（2026-08-10）

流水线层级链此前有四个互相矛盾的版本（本仓词表说"项目→集→分镜→媒体"、`prd-v2/project.md` 说"项目→集→片段"、`prd-v2/production.md` 说"集视图→场卡→段落工作台"、数据库是 `project→episode→(scene 可空)→shot`）。裁决：

- **现役层级 = 集 → 场 → 镜头**，三个概念，与数据库对齐；
- **「段落」「片段」作废**，入禁用词表。代码里"段落生成"的实际定义是 `media_kind==="video" && scene_id`（`src/modules/generation/routes.ts:894`），即**段落本来就等于场**，此前是文档比代码多造了一个词；
- **「段落工作台」改名「场工作台」**；
- 数据库事实要补进文档：**`shots.scene_id` 可空**，即镜头可以不属于任何场。此前没有任何一份文档提到过这条。

## 权威怎么判（后者第 3 行的规则，2026-07-07 拍板）

术语口径的权威 = **拍板时间 + 拍板人**（以决策记录为准）。**任何文件不得自称权威来源、不得声明自己免疫**。所以：
- 两份文件冲突时，不看哪份"自称权威"，看哪条有更晚的拍板记录
- 命名优先级：供应商官方词 > 行业标准词 > 社区行话 > 产品概念词
