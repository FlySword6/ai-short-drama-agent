# 分诊标签

分诊技能用五个标签表示单子的处理状态。本仓用默认名，不改写。

| 角色 | 标签 | 什么意思 |
| --- | --- | --- |
| 待分诊 | `needs-triage` | 刚进来，还没人看过 |
| 待补信息 | `needs-info` | 看过了，但信息不全，得回去问 |
| 可交给 agent | `ready-for-agent` | 说明足够清楚，AI 能直接开工 |
| 需人处理 | `ready-for-human` | 得人来判断或人来做 |
| 不修 | `wontfix` | 决定不做，写明理由后关掉 |

本仓原来没有这套标签，用默认名不会跟已有标签撞车。
