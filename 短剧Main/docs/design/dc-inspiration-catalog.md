## 六、DC 反复强调的判据(不是灵感,是尺子)

这些不属于某一版本,是每次做设计与排期都要过的判据:

1. **克制**——微信那样的克制感;一屏一个核心行动;默认折叠;删掉的不许换形式加回来;
2. **影视/内容气质**——片场语言(片场/分镜/粗剪/开拍/过审/连播),拒绝技术 SaaS 味;
3. **复用成熟方案**——「尽可能复用和参考成熟产品和已有 github 高 star 项目代码」,不自造轮子;
4. **第一性原理**——「用户在界面上摸得着的体验才是产出」,文档与里程碑只是手段;
5. **简化人脑负担**——「平台就是要简化人脑对于 context 的思考难度和管控难度」(已成 ADR-0003 的 context 层原则)。
