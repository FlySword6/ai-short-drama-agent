## 一、三条模型判据(原型的地基,违反=白建)

1. **非线性工作空间(R109)**:真实流程=选题+大纲 → 剧本+分镜表 → 资产参考检索/推荐+编辑适配 → grill 清细节 → 生产抽卡,
   但**过程不是线性的**——反复修改调整检查、中途有等待去干别的、并行多任务、还会用外部工具(chatgpt/ps/excel)。
   原型判据:①任何页面都能「离开再回来接着做」(全局任务队列+「继续上次工作」回归锚);
   ②外部工具往返口(编译稿复制全文/资产上传);③步骤条只是模板不是骨架。
2. **控制包中心(R96)**:工作台主对象=粗剪素材(一场戏/段落),不是单镜。控制包在素材级锁一次(六 lane 词表开放),
   镜头只留差量;**换镜不换包**。
3. **段落一次生成(R119)**:生成单元=整段多分镜视频(seedance 2.5 支持 30-180s 一次出),不是逐镜生成。
   编译稿=整段多镜头结构化稿(官方语法,见 OFFICIAL-DOCS-MAP §三);开拍=按段起一个任务;
   抽卡版本挂段落产物;镜头列表=段内结构标注+局部重生成入口(交互暂做标注位);先出样片 0.6× 保留(整段先样片)。

## 二、页面清单(原型覆盖面,带各页一句定位)

**全局层**
- 游客首页+登录(Figma 01 已有,照搬)
- 项目管理(四列看板:备戏/在拍/送审/已交付;「继续上次工作」横幅=回归锚)
- 资产中心·检索态(族筛选树+dim-chips+资产卡带 CH 编号与元数据行)
- 资产中心·备戏台态(检索|备戏切换;为一场戏备料;「已就位/还缺」;R95 杠杆的主场)
- 数据看板(消耗明细为主,Table 组件已有;轻做)
- 全局生产队列(顶栏 chip+展开面板;跨页常驻;测试站已上线的 K2W 是它的前端雏形)
- 管理后台(超管资产入库批次流:传包→预检→确认→入库→发布/隔离——spec 见 context repo,#92;轻做框架)

**项目内层**
- 选题(52API 榜单参考+选题卡;接口形状已裁 R118)
- 剧本+分镜表(R110:拆解服务于这一环、允许反复调整;剧本导入 docx;拆解产物=草稿区→人工确认)
- 资产(项目资产+从通用库检索推荐+编辑适配;肖像/定妆两件套位,承 R120 肖像标准化)
- 生产·工作台(按 §一 三判据建;这是原型的心脏,Figma 04 帧迭代后为准)
- 消耗(计价透明:档位=计价单位不是能力天花板,V-08)

**贯穿件**
- grill 反问(信息不足时 agent 反问补全,不拿默认值糊;注册期+创作期两处)
- AI 工作区入口(顶栏,按 codex 架构先基础对话,R99)
- 业务语言(R105:全部文案人话,失败给下一步)
