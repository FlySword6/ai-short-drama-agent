# 设计稿:实验室 · 模型竞技场(#23,2026-07-23,Fable)

定位:0.2.0/0.3.0 之间的**实验室**页(丽芬稿被否后重出)。目标三个:
①新模型/新档位/新拍法上架前的**实测场**(能力档解锁流程第 1 步的产品化);
②同题多模型对照,沉淀**平台自己的评测数据**(数据飞轮,防复刻条 30);
③给创作者一个"花小钱试效果"的安全沙盒。遵守 platform-ontology.md、
付费红线(每次生成人工确认)、能力档合同(档外组合不可提交)。

## 一、对象(接本体)

- **对局 bout**:一次对照实验=同一输入(提示词+参考集)× N 个参赛档位
  (2-4 档,来自 capability-tiers,含 experimental 档——竞技场是
  experimental 状态档的唯一可见入口);
- **评判 verdict**:用户对对局产物的选优+维度评分(一致性/质感/构图/
  指令遵循,四维 1-5),写 events 埋点(条 14/23 采纳信号同族);
- **实验项 experiment**:官方挂出的玩法实验(首批:条 8
  VisualStoryboardPrompt——宫格/运镜小样拼时间轴长图喂 i2v,对比
  逐镜生成的一致性),用户可跟跑并提交评判。

## 二、页面结构

1. **发起对局**:输入区(提示词+可选控制包引用,R2:引用只从工作台
   就绪包取)→ 参赛档位多选(档卡=模型+参数+单价,experimental 标
   「实验档」)→ 确认卡示**总价=各档报价之和**,人工确认后并行提交;
2. **对局视图**:并排产物卡(盲评模式默认开:先看图后揭晓模型名,防
   品牌偏见)→ 选优+四维评分 → 揭晓;
3. **榜单**:按媒介类型聚合历史对局的胜率/维度均分(平台内私有数据,
   不做公开排行营销);管理员视图多一层:实验档转正建议(胜率+样本量
   达阈值提示走能力档解锁流程第 2-4 步);
4. **实验项列表**:官方实验卡(说明+跟跑入口+当前结论状态)。

## 三、纪律与边界

- 竞技场生成走 generation 主链同一记账(cost_entries 可见,无特殊费率);
  预算护栏:单对局≤4 档,experimental 档需管理员开放可见;
- 评判数据只进平台库(埋点表),不回显个体用户行为给其他用户;
- 不做:公开投票、模型厂商对外榜单、自动按胜率切默认模型(转正必须
  人走解锁流程);
- 一期不含视频对局(成本高),图像先行;视频随预算授权再开。
