# P-02b 生产页签·集视图 设计规格(Figma 施工图纸;2026-08-02)

> 位置:项目内二级条「生产」页签的新形态,取代旧 StoryboardPage。SPEC 区将新增一行(P-02b);帧画在 05 页 P-02 旁。
> 判据:Readme 八规则+V-24(唯一 primary)+R17④(时间线置顶)+承接表 a(审核/交付位)。

## 布局(自上而下)

1. **整集时间线带**(R17④/④b,置顶):横向缩略带,每格=一场的当前主版本首帧(有粗剪素材)或状态底(备戏中=中性纹理/未拆解=虚线格);格宽 96,hover 放大浮层;点格=滚动到下方对应场卡。右端集级进度语「第 N/M 场已交付」(mono 数字)。
2. **下一步条**(唯一 primary 所在):按集状态给一个主动作——未拆剧本→「去拆剧本」(→P-06);已拆未备→「去备戏」(→P-03b);备好未拍→「进工作台」(→P-04 首个未完场);全部已交付→「送审交付」(开审核交付面板)。条内左侧一句话状态(片场话:「第 3 场备好了,可以开拍」)。
3. **场/段落卡列表**(主体):每场一卡,行内=场号+场名(宋体)/状态 Badge(中性色:未拆解/备戏中/生成中·accent 呼吸/已交付)/就位 x/8/主版本缩略/入卡=进 P-04 该场。卡右缘 Ghost:「备戏」(→P-03b 带场参数)。生成中的场:行内细进度(排队第 N)。
4. **集级操作区**(收进「更多」下拉,拆掉八按钮堆砌):审核队列(承接表 a)/交付本集(承接表 a)/导出本集(留位)/预览全集(时间线带已承接快览,此处保完整播放)。全部 Ghost/菜单项,不占 primary 预算。

## accent 账(≤3):primary 1+生成中呼吸 1+壳导航 2(壳账另计)=页内 2,合规。

## 空态
- 无剧本:时间线带=虚线格×6+「这一集还没有剧本。去粘贴或导入,拆完镜就能开拍。」(杠杆语气)+primary=去拆剧本。
- 已拆无生成:格=场名底,状态语「6 场备戏中,还没开拍」。

## 数据接口(现有,零新后端)
scenes/shots(P-06 确认写入)/项目生成列表按 shot_id 归场(P-04 同源)/主版本 selected_video_result_id/审核交付=review-delivery-panels 组件平移接线。

## 交互时长
时间线格点击=页内滚动(0.2s);入场卡→P-04(0.3s);下一步条跳转(0.3s);与动效总表同源。
