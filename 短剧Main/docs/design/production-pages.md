# 生产:页面与流程设计(定稿)

状态:DC 与 Fable 对谈定稿(2026-07-22)。Kimi 生产域改版以本文为准;后端配套件见文末分工。
一句话:**生产页卡的任务不是"生产分镜",而是导演意图澄清+参考控制包生产;
每一集的交付物是可导出给剪映的视频片段。**

## 一、对象模型(叫什么、装什么)

```
项目 → 集 → 粗剪素材(交付单元,可导出剪映) → 镜头(时间轴内部结构)
```

- **粗剪素材**:一次(或一组)视频生成的交付单元,内含一到多个镜头的时间轴。
  就是控制包三层模型里的"生成片段",现在有了产品名;数据上复用那一层,不建新概念。
- 新建粗剪素材用**网格加号卡**(与新建项目同款交互)。
- 每个粗剪素材配一份**文字描述**(原"分镜内容"),它是结构化剧本的叙事来源。

## 三、核心工作流(从进项目到出片)

1. 进入项目,写(或导入)**文字描述**;
2. **AI 出资产匹配草稿**:文字描述过语义检索,把角色/场景/道具/参考自动配上——
   用户校验、增删、确认(第一版走检索,不等对话式);
3. **意图澄清**:在工作台把这段文字描述细化成镜头时间轴+参考选择——已匹配资产在
   提示词框里**可 @**(就是结构化剧本的槽位:@图像N/@视频N 编译时分配,创作层用
   稳定资产 ID,合同见 structured-script-ir.md);
4. **参考控制包生产**:按需去四个生产页(下节)补参考材料;
5. **生成**:两条通道并存——快速通道(直接文生视频)始终可用;控制通道在**人工标记
   就绪**后出现「生成本粗剪素材」;「一键生成本集」=对人工标记就绪的粗剪素材依序
   执行——**两个动作两个界面,不共用**;
6. 交付:成片片段导出剪映(现有交付清单流程)。

## 四、工作台:五个标签页(2026-07-22 DC 用后裁决,替代"参考栏/车间"版)

工作台就是五个普通标签页:「**工作台 | 图片 | 视频 | 音频 | 3D 导演台**」。
四个功能页是一级页签,用户直接点进去干活;第一个页签放三样:文字描述、**参考清单**、
生成按钮区。功能页产出自动出现在参考清单对应组里,回到工作台不丢上下文。

**界面用词纪律:零自造词。**"参考栏/备料/车间/基线"这类词一律不上界面;分组直接叫
角色/场景/道具/运镜/参考视频/音频;跳转按钮叫「去图片页/去视频页/去音频页/打开 3D
导演台」;有参考=✓+数量,没参考=一句白话建议(如「还没有运镜参考。可以写一句机位
描述,或在 3D 导演台摆一个」)。内部优先级(P0/P1/P2)不外显。代码层 lane 字段名与
API 契约(control-package-and-lanes.md)不变——这是纯界面语言约定。

「就绪」仍是人工一次点击(记 who/when,可撤销),完备度只提示不阻塞;快速通道
(直接文生视频)永久合法。每组给「从资产库选」直接挂库存资产的入口。

四个功能页的输入输出:

| 页面 | 输入 | 输出(role) | 依赖的外部能力 |
| --- | --- | --- | --- |
| **音频** | 台词/旁白文本、音色选择 | 配音/旁白(声音参考) | 火山大模型语音合成(346 音色已勘)、声音复刻;计费开通 Sol 勘察 |
| **3D 导演台** | 素模+摆位+运镜 | 参考图(镜头故事板)、运镜参考视频 | 已有 |
| **图片** | 文字+角色/场景/风格参考 | 分镜图/设定图 | seedream 流程已通;宫格切分见下节 |
| **视频** | 参考清单全部+文字描述编译的提示词 | 粗剪素材片段;快抽小样(动作/运镜参考) | seedance 正式档+便宜档快抽 |

**视频页两档**:便宜档快抽运镜/动作小样(可多次迭代验证控制力)→满意后 seedance
一次到位;快抽产物自动挂回参考清单。两档都走估价→人工确认红线,便宜档批量估价一次
确认;快抽产物默认不进交付。

## 五、宫格切分:就地流转,不绕资产中心

切分完成后直接两个动作:
- **选格创建粗剪素材**(可多选,LibTV 分镜组同款意图);
- **高清化**(火山 LAS 超分算子,Sol 勘察清单内)。
产物按 role=镜头故事板后台静默入库,生产流不打断。

## 六、与结构化剧本合同的接缝

文字描述=IR 的叙事来源;资产匹配草稿=IR 的 assets+refs;意图澄清=IR 的镜头字段填充;
参考控制包=编译产物+槽位映射(slots)组包。@ 艾特的格式规范即槽位规范,不另造语法。
