- **次元神笔**=存量前身产品:只有生图+生视频真被用(API 页面化),资产模块没人用、无埋点、剧本功能弱——我们平台即其改造与替代。
- **FF**=内部另一系统:其项目管理代码曾拟整合;「FF 导演链路」=FF 系导演工作流(DC 战略图原词);<!-- lint:allow-term 引用战略图专名 -->紫阳(FF)=提示词优化 agent 合作人。

## 二、一线真实工作流(对照我们动线)

编导拿剧本→DeepSeek 整理(角色/穿搭/性格/走向/道具/场景)成表→生图师(即梦/香蕉 Pro/Workfor)做人设场景→C-Dance(Seedance)2.0 生视频(自由度高效果好,音频参考/视频参考/换脸)→SD2.0 成片含对口型→剪映精剪。管理靠 Excel+企微文档,资产人工管理。
**与我们对照**:剧本拆解表=分镜表✓;人设场景参考=控制包/备戏台✓;「统筹表(演员/道具/场景穷尽后人为做减法,主角优先)」=备戏与控制包的原始需求形态✓。

## 三、痛点与需求 → 版本计划对照

**已被现行版本覆盖**:资产库入库/复用/检索、项目看板、选题榜(17K/52api)、提示词优化接真模型(已合流)、音色库(声音工坊)、版权与 AIGC 合规、导演检查以集为节点(集视图)。

**新输入(版本梯弹药,按分量排)**:
1. **题材风格 skill 模板**(2D 言情/武侠/悬疑/3D/真人——从人设场景起全环节规范)=「风格模板」列第一版工具五能力之首(05-29 决策:风格模板/参考图/资产/分镜先验证)。
2. **返工现状数据=12 人时的分母**:纯抽卡(定人设→粗剪)2-3 周最耗时;审核 3 轮返修 2 轮,集中前 10-15 集——提效主战场=抽卡次数与返工轮次。
3. **分镜侧边栏建议**:参考潘导能力,可枚举部分模式化(群戏固定机位),实时生成部分给建议,按导演水平调自动化比例;「AI 分镜影响想象力,应导演先设计、AI 再讨论光影节奏」=辅助不代笔的红线。
4. 小痛点直进修补族:历史记录时间筛选、生成任务取消、提示词过长查看不便、下午生成易失败(稳定性)。
5. **超分 2K/4K**(甄界的自动提画质)与**去字幕**(现用字节能力,慢)=成片质量链两件。
6. **粗剪自动化**方向(剪映不可替代性分析;多轨/弱起弱出)——远期。
7. **体感数据基线方法论**:蒙特卡洛采样 10-20 人,非结构化体感→数据基线(=Q3「人时口径形成」的方法,与我们 UX 基线同族)。
8. Codex 工作台包进产品给编剧/导演(=AI 工作区/Pi 的定位佐证)。
9. 角色 0→1 SOP 沉淀+北美肖像权申请(合规线补充);AI 脸相似度>50% 人工审核+法务案例库。
