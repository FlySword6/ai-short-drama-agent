## 总判断

信息架构本身成立:项目 → 生产(集/粗剪素材)→ 工作台(五页签)→ 功能页,双通路在,
付费红线在。真正的病在两处:

1. **3D 导演台是"假页签"**:工作台里点「3D 导演台」页签,出来的不是导演台,
   是一张中转卡(一句介绍+又一个「打开 3D 导演台」按钮);点按钮才真打开,
   而且是整页路由跳转——顶栏都换掉,当前粗剪素材的上下文全丢;导演台本身
   也不知道你从哪个素材来的;做完导出还要自己返回→重进工作台→手动归组,
   一来一回五步。这就是 DC 说的"点到页卡还得跳转,体验很差"。
2. **开发者语言渗透到界面**(全站性):按钮上写 HTTP 动词和实现细节、
   设计说明整句当按钮文案、降级说明重复刷屏、旧词清尾漏网。功能是全的,
   但界面读起来像验收现场,不像产品。

## 逐项问题清单

### A. 3D 导演台集成方式(最高优先)

- 工作台「3D 导演台」页签 = 中转卡,点开还要再点一次按钮,然后整页跳转丢上下文。
- 导演台是项目级页面,不带粗剪素材上下文;导出后需要用户自己回工作台手动归组
  (页面上原话:"当前请从导演台导出后,到图片/视频页归入")。
- 3D 导演台入口散在三处:项目内导航、生产页本集按钮行、工作台页签,行为不一。
- 导出菜单在无机位时,三个选项的文案整个被替换成「请先新增机位」×3——
  用户看不到这三项本来是什么。禁用要保留原文案+说明原因,不能吃掉文案。

### B. 界面语言(全站清扫)

开发者语言直接可见:

- 项目资产页移出按钮:「移出 = DELETE reference,只解除引用,不影响资产中心本体」
- 导演台:「保存场景(乐观锁 v0)」
- 设置页:「自定义版本仅保存在本机(服务端合同未接)」
- 消耗页副标题:「复用项目统计缓存,显示当前项目总计和参与用户」;
  口径说明里「后端金额字段恒等读取」

设计说明当按钮文案(按钮应是短动词,说明进悬停提示或副文本):

- 「导演/美术确认参考可用后点击标记就绪——人工判断,可撤销,不做机器门禁
  (当前保存在本机,后端字段接入后全端同步)」→ 应为「标记就绪」
- 「快速通道:直接文生视频,不要求任何参考准备,始终可用」→ 应为「直接文生视频」
- 「便宜低帧低分模型先抽个运镜/动作小样,生成结果直接归入本组(模型分档接口
  接入前仍走默认模型)」→ 应为「快抽运镜小样」
- 「勾选卡片后可批量提审」→ 应为「批量提审」(未勾选置灰)
- 「还没有人工标记就绪的粗剪素材:进工作台点「标记就绪」」当主按钮文案

降级/预告说明刷屏:

- 参考清单六组每组一行「原型演示:归入记录只存本机」×6 → 收成页面级一条
- 资产中心每张卡三个置灰按钮「资产编辑后续接入」「转为通用资产(接口接入后
  开放)」「下载资产(受保护下载接口接入后开放)」→ 收进「更多」菜单
- 审核状态四行说明在项目资产页和资产中心各常驻一份 → 收进「?」帮助浮层
- 消耗页「记账与复核口径」两大段常驻 → 收进帮助浮层

### C. 术语清尾漏网(用户可见旧词与黑话)

「分镜」残留(应为「粗剪素材」或语境改写):

- 工作台顶栏一整排「分镜1 · 中景 · 平视」…「分镜6 · 远景」(最显眼一处)
- 生产页进度条第一步「导入分镜」;进度提示「分镜 1 还没有可用图片」
- AI 工作区上下文名「分镜管理」
- 图片页空态「暂无分镜图」
- 设置页提示词模板 tab「分镜主图」
- 功能预告「对话式拆分镜——剧本贴进来,分镜草稿出来」

黑话残留(上一轮清扫漏网):

- 设置页预告卡标题「Pi 主动备料」
- 生成抽屉「估价只备料,不创建任务」
- 工作台「基于此编辑」按钮悬停提示「以此版本为基线做受控编辑…」
- 离线演示项目描述「最近处理 EP1,备料对照」(demo 数据)

### D. 生成输入框离 LibTV 标准形态的差距(图片/视频页)

LibTV 节点输入框:快捷入口 chips → 参考缩略图行 → 提示词 → 参数行
(模型/画幅/时长/数量)+ 实时积分估价显示在发送键旁 → 发送。对比我们:

- @资产快捷 chips 已有(好,保留);
- 参数收在「参数」按钮弹层里,应明摆成输入框底部一行;
- **发送前看不到估价**——估价只在确认卡里出现。应输入框常显实时估价,
  点生成再进人工确认(红线不变,费用前置可见);
- 视频页空态文案「图片确认后,再填写视频提示词生成」与「直接文生视频始终可用」
  自相矛盾,会让用户以为必须先出图 → 改为「可以直接文生视频;有确认图时
  默认按图生视频」;
- chips 分组名「未标职责」偏内部 → 「其他资产」。

### E. 视觉物料感(与 LibTV 差距,分期做)

- 项目卡、粗剪素材卡、参考清单条目、使用资产 chip 全是纯文字;有产物后应显示
  首帧/缩略图,项目卡给海报位。内容公司的工具,画面要先于文字。
- 音频页是「待接入」×3 的占位壳,却占着一级页签(S3 接 346 音色时填实)。

### F. 细节 bug

- 工作台标题「《《老公诈死》》 · 工作台」——项目名自带书名号,模板又套一层;
- 资产中心统计「个资产 · 3 已入库 / 5 待入库」——句首数字丢失;
- 数据看板生产摘要「570」无量词标签;
- 设置页导航「检查更新」在 Web 产品里语义存疑(桌面端概念)。
