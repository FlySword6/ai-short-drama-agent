## 一、域动线

选题(P-05 热度榜+题材卡)→ 立项 → 剧本(粘贴/导入 docx·Excel)→ 拆解(AI 出场/镜结构草稿)→ 人工确认(写 scenes/shots 真源)→ 故事板视图(P-06b)→ 生产域接手。
- 拆解只到场/镜结构,提示词在资产与生产环节组装(既定裁决,防拆解越权写小作文)。
- 非线性原则:每步可回退重跑;确认前草稿区随便折腾,确认后进真源要走版本(script-versions 已有)。

## 二、拆解增强(R131②⑦,v0.3.0 后端,flash 化候选)

- 角色表单补全:拆解时抽性别/年龄/外貌描述/性格标签(现仅名称)——候选层写入,人审转正(R116 同源);与资产库角色 entity 预关联(同名提示绑定)。
- 分镜提示词整合返回:拆解结果带每镜「结构化要素」(主体/动作/画面/镜头语言四栏,R19 训练表词表化)——只出要素不出成文提示词(组装权在编译稿)。
