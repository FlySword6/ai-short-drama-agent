## 一、三线定义

- **A 线 CLI+Skills**:平台能力经 CLI 暴露给外部 agent;每个产品功能先有 API 合同(R28),CLI 与界面消费同一合同;下载页轻做(一页+一键安装命令)。
- **B 线界面智能化**:界面内建 AI 能力全部走 ai 网关 purpose 体系(quality/fast 双档);flash 到位后 fast 档统一换源(路由稿 v1.1 已预定稿);候选面=提示词优化/翻译/拆解增强/资产语义标签/剧本一致性检查/P-13 读图。
- **C 线 Agent 支持**:外部 Agent 操作平台的通道(pi 三角色体系);操作留痕+中间产物前端可见(R28b/R101);agent 标识与多端登录按行业标准(日0728③)。

## 二、硬约束

1. 付费生成永远人手点击(Pi 口径,全 Agent 通道同判)——Agent 可以备料/报价,提交=人。
2. AI 只写候选层,转正必走人审(R116 全域同源)。
3. Agent 会话标识独立(session 标注 agent 类型+UA 规范),审计可分人机。
4. 模型选型不受现有渠道拘束(R152),接入三件套=注册表+档位+参数矩阵。

## 三、排期归属

- v0.3.0:flash fast 档换源(第一批 purpose)+拆解增强(在施)+P-13 读图;
- v0.3.x:资产语义标签自动化/剧本一致性检查/CLI 下载页+核心命令集;
- v0.4+:Pi 高级能力(联网/知识库/记忆)/画布/agent 编排。
