## 0. 结论速览

1. **剧本+分镜合并为一页「制作」**（用户裁定 2026-08-13）。分镜是剧本的输出，同一集在同一屏完成「写剧本 → 出分镜」（左栏剧集 + 右栏 剧本→资产引用→分镜，§4.2）。壳导航收敛为 `制作 / 资产` 两个工作页，不再有 3 阶段 tab、更不是 6 页签。
2. **成品不设独立页。** 成品就是分镜的产物——每镜「出片 → 定成片 → 下载」已在分镜卡内完成（段⑤）。只补一个**集级**动作「打包本集成片」放在**制作页分镜区头**，替代被删的下载页。
3. **删除 `图 / 视频 / 下载` 三个只读页签与页面**：它们的内容已经内嵌在 素材/分镜 页里（见 §1 诊断），留着就是重复。
4. **项目是容器**（R2-11 修订 2026-08-14；**2026-08-17 再修订：两层并单条；同日二次裁定：返回按钮常驻带文字**）：壳 = **一条自适应导航条**——左起 logo 标（点回项目列表）+ `‹ 返回项目列表`（工作页/配置页常驻）/ `‹ 返回分镜` / `‹ 返回素材`（详情页，历史返回）+ 名称区（《剧名》，详情页附具体名称，最后一段字重最重），中右 `制作/资产` + `⚙ 项目配置`（仅项目内渲染），右端恒为模式切换 + 用户名；内层容器与内容同宽对齐；`[导入整部剧本]` 在制作页页头动作位（右侧）。详见 §2.2。
5. **统一宽度**：标准工作页 `max-w-[1440px]`，**2xl(≥1536px) 起弹性放宽到 `max-w-[1920px]`**（2026-08-14 R2-1 裁定，808-14 更新从 1600px→1920px）；~~配置页宽度 R2-8 对齐工作页（`max-w-[1440px] 2xl:max-w-[1920px]`）~~（**2026-08-17 三次裁定推翻：配置页宽度改为随屏幕伸缩 `w-full`、无上限——见 lite-config-tabs-and-style.md §4.1.3 追加裁定与 R2-8 条目更新；G3 门禁配置页专属断言随之改写**）；原窄表单档 `max-w-3xl` 退役；删掉 `max-w-6xl` / `max-w-5xl` 混用（`max-w-[1920px]` 为 2xl 登记款，非旧 `max-w-[1920px]` 裸宽）。
6. **每页一个主动作**：accent 强调色只给一个主按钮，其余 outline/ghost。
7. **弹窗统一**：同一套 Dialog（标题 / 说明 / 主体 / footer）；**付费动作弹窗必须带报价行 + 「一次点击只创建一次任务」提示**（§5.3 付费红线表达）。
8. **空项目首跑单独设计**：每个阶段都画了空态引导原型（§4.7）——空项目第一次进入不落空，空态链引导用户顺着流程走完。
9. **字阶与弹窗锁死既有 token，不发明新规格**：字体层级直接用 `tw.css` 的 A4 定稿（页面标题 20/600、区块标题 15/600、正文 14/400、辅助 12/400），修掉 `lite-script-page.tsx` / `lite-shots-page.tsx` 的 `text-2xl` 漂移（D10）；Dialog 用组件既有四档（small/medium/large/wide），禁 `max-w-*` 裸覆盖（§3.2 / §3.4）。
10. **分镜详情页 = 独立左右分栏工作台**（§4.3）：分镜的字段级能力（场景参数 / 对白 / 动作 / 关联资产 / 视频提示词 / 视频版本）在列表卡里被压掉，统一落到这个独立详情页——左栏「已选资产 + 分镜内容」整体纵向滚动、右栏「视频与版本 + 视频提示词」分层（版本条横向滚动、提示词竖向滚动），左右等高适配屏幕可用高度、比例左 2 右 3；**版本 = 可点开的实体**：点某版本开「版本详情弹窗」、`⋮` 进「版本编辑弹窗」（整条重新做 / 只改某几秒 / 删掉这个版本）；片段编辑以 `lite-shots-page.md` 为准。
11. **高度模型两模式（§3.7）**：**不是所有页面都固定适配屏幕高度**。绝大多数页（项目列表 / 素材等）是**内容随页面滚**（整页一个滚动容器、页内不设子滚动区）；制作页 / 分镜详情 / 资产详情 三个「工作台」页用**视口固定分栏**（各自独立纵向滚动）——判定规则见 §3.7。**配置页 B′（R2-8 二次裁定）**：高度固定为屏幕可用高（与工作页同公式），但**不做整区滚动层**，模板内容 Textarea 内部滚动（§3.7 / §4.6）。

**R2-1 · 各页中心内容过小且不统一，未适配不同屏幕宽度**

- **用户问题**：Lite 各页面中心内容偏小、宽高不统一，没有随不同屏幕宽度自适应。
- **现状核对**：容器宽度已按 §0 第 5 条收敛——`lite-projects-page.tsx:72`、`lite-assets-page.tsx:751`、制作页、分镜详情页均 `max-w-7xl`（DOM 实测 1280px），`lite-project-config-page.tsx:646` `max-w-3xl`（768px）；但「中心内容过小 / 未随屏宽自适应」的感知仍存在——宽屏（1920+）下 1280px 居中两侧留白大、内容显小，窄窗/移动端断点表现未逐页复核。
- **期望修复方向**：按用户本轮裁定复核全部 Lite 页面（含分镜/资产详情）的宽度档位与响应式断点；宽屏下容器是否突破 1440px 上限由用户裁定（§0 第 5 条如被推翻需在正文同步修订）；窄屏断点（制作页左栏 w-56、卡片网格列数）逐页走查。
*60|- **已实现（2026-08-14）**：用户裁定「宽屏弹性到 1600px」——标准工作页容器加 `2xl:max-w-[1920px]`（制作页 workspace 主/loading/empty/error 四处、assets、projects、asset-detail、shot-detail 主/加载态），2xl(≥1536px) 起突破 1440px 上限；配置页当时保持 `max-w-3xl`，**后被 R2-8（2026-08-14 二次裁定）推翻**——配置页宽度亦对齐 `max-w-7xl 2xl:max-w-[1920px]`，`max-w-3xl` 退役；G3 门禁登记 1920px（§3.1 表同步）。

**R2-2 · 顶栏下方横线在页面滚动时割裂内容**

- **用户问题**：导航栏下方那条横线，在页面滚动时把内容割裂了。
- **现状核对**：`lite-shell.tsx:118` 顶栏 = `glass-panel sticky top-0 z-[calc(var(--z-float)+1)] border-b`；`glass-panel` 为半透明材质（`tokens.css` `--surface-glass: oklch(0.230 0.012 260 / 0.88)` + 20px blur）。sticky 顶栏吸顶后，页面内容从顶栏下方滚过，88% 透明底 + `border-b` 1px 横线把滚动的卡片「切」成两段，视觉割裂。
- **期望修复方向**：去掉 `border-b` 横线或改为不透明底 + 顶部渐变遮罩，让 sticky 顶栏与滚动内容自然过渡（不出现横切感）；口径与 §2.2 壳顶栏线框一致。
- **已实现（2026-08-14）**：去掉 `lite-shell.tsx` 顶栏 `border-b`，`gap-6`→`gap-5` 收紧；sticky 顶栏与滚动内容以 glass 半透明底自然过渡，无横切感。

**R2-3a · 一键生成本集不应要多余人工确认，点击后默认采用解析结果**

- **用户问题**：一键生成本集流程不对——不需要多余的人工确认，点击后应默认采用解析结果（解析不属于付费生成链，自动采用不违反付费红线）。
- **现状核对**：`lite-workspace-page.tsx` 已存在自动确认路径——`autoGenerate()`（:736）提交后轮询，`latestRun.status === "draft"` 时自动 `confirmScriptBreakdown`（:512-530），解析即采用、不落 review 态。但 demo 离线模式拦截一键生成（「离线演示不会一键生成」），**真栈端到端未复核**：用户感知到的「多余确认」可能来自旧实现或真栈某分支未走到自动确认。
- **期望修复方向**：真栈端到端验证「点一次一键生成本集 → 解析 → 自动采用」无多余确认；确认 `waitingForSubmittedRun`/轮询时序在 draft 到达时不闪 review 态；批量生成仍保留一次人工确认（批量生成契约属完整版范围，不在 Lite 版流程文档 `docs/lite-oneclick-generate-episode.md` 内）。
- **已实现（2026-08-14）**：真栈核实 auto-confirm 已存在（`lite-workspace-page.tsx:512-525`，draft 态自动 `confirmScriptBreakdown`），无需新增代码；修复 view 计算——`waitingForSubmittedRun` 分支加 `autoGenerating ||`，一键生成轮询期间 draft 态稳定显示「正在生成分镜」、不闪 review 态。批量生成仍保留一次人工确认（契约不变）。

## 2. 信息架构（新）

### 2.1 创作逻辑

用户原话的简单逻辑：`项目 → 剧本 → 资产 → 分镜`。**剧本和分镜是同一集的上下半场**——分镜由剧本解析产出，合为一页「制作」；资产是项目级素材库（跨集复用），制作页内只读展示本集引用，管理在资产页。成品**不占独立位置**（它是分镜的产物）：

```
项目（容器）
  └─ 制作页（一集工作台：剧本 → 资产引用 → 分镜，?ep= 跟随）
       左栏：剧集列表（每集独立状态）
       右栏：一键生成 → 当前集内容（可编辑）→ 本集资产引用（只读）→ 分镜卡片（唯一滚动区）
  └─ 资产页（项目级素材工作台：弹窗建资产 + 详情左右分栏）
```

- **合并依据**（用户裁定 2026-08-13）：分镜是剧本的输出，「选一集 → 写剧本 → 出分镜」在同一屏完成，避免两页来回；分栏 + 固定高度让两者互不干扰（§4.2 高度模型）。
- **资产为什么仍独立**：资产是**项目级**（跨集复用），不是集级；制作页只放本集引用的只读条，编辑仍去资产页。

### 2.2 壳导航（单条自适应条，2026-08-17 用户裁定，修订 R2-11 两层结构）

壳 = **一条**全局导航条，所有 /lite 页同一结构，内容随页面自适应。R2-11 的两层结构（全局条 + 项目条）退役：进项目后头顶三层横条（全局条 48px + 项目条 48px + 详情页返回行）过重显乱，且 logo 点击与「〈 全部项目」去向重复（都回 `/lite`）——两个控件干一件事（2026-08-17 裁定依据）。

```
┌────────────────────────────────────────────────────────────────────────────┐
│ ◈  ‹ 返回项目列表  《剧名》          制作 ●  资产 ○   ⚙ 项目配置 │ 精简版  Alice │   ← 工作页/配置页
│ ◈  ‹ 返回分镜  《剧名》 · 1-2·广场     制作 ●  资产 ○   ⚙ 项目配置 │ 精简版  Alice │   ← 详情页
└────────────────────────────────────────────────────────────────────────────┘
  ↑logo标 ↑返回(常驻带文字,按页给语义)  ↑名称区(最后一段最重)   ↑项目内渲染  ↑右组(恒在)
```

- **logo 只放太极标**（`BrandMark`，不带「中文在线AI短剧平台」文字排——单条摆得下的前提，用户原话「只要有一个logo」）；点 logo 回项目列表（`/lite`），兼任原「〈 全部项目」职责。
- **名称区**（项目内渲染，页面具体名称上导航——用户原话）：
  - 工作页（制作 / 素材 / 配置）：《剧名》`text-sm font-medium text-ink-1`。
  - 详情页：《剧名》`text-sm text-ink-2` + `·` + 具体名称（镜名 / 资产名·类型）`text-sm font-medium text-ink-1 truncate`；页面内原「返回 + 标题 + 副标题」行**整行删除**（§4.3 / §4.4.2）。
- **返回按钮常驻且带文字说明**（2026-08-17 二次裁定，用户原话「顶部的导航栏应该有明确的返回按钮和说明」）：项目内**每页**都有返回，去向按页面语义标注在按钮文字里——
  - 工作页（制作 / 素材）与配置页：`‹ 返回项目列表`，固定回 `/lite`（确定性去向；logo 点击同向，双入口不冲突）。
  - 分镜详情：`‹ 返回项目详情`（**固定回制作页**（项目详情，带 `?ep=`），2026-08-18 用户裁定：顶栏切镜 tab 压历史栈，历史返回会退回上一镜，返回必须确定）；资产详情：`‹ 返回素材`（历史返回，无历史回落素材列表）。
  - 返回文字**常显**（不设 `hidden md:inline` 之类的窄屏藏字——「明确」就是不能只剩箭头）。
- **项目内中右组**：`制作/资产` 两工作页入口（✓ 完成 / ● 当前 / ○ 未到，§5.5，**不锁跳转**）+ `⚙ 项目配置`（与项目卡「配置」同一入口的两种出现位）。剧本/分镜不单列入口；**没有**「成片」页签（成品在制作页分镜区段⑤ + 集级打包）。
- **项目列表页（`/lite`）**：`projectId` 为 null——名称区 / 返回 / 工作页导航 / ⚙ 整段不渲染，只剩 logo 标 + 模式切换 + 用户名（页面本身保留自己的页头，§4.1）。
- **最右组恒在**：模式切换 + 用户名（原第一层全局条内容并入单条右端）。
- **对齐保留**（R2-11 成果不回退）：单条为全宽 glass 条，内层容器 `mx-auto w-full max-w-[1440px] 2xl:max-w-[1920px] px-4` 与 §3.1 内容容器同宽同内边距——右组随内层容器对齐内容右缘，不再贴视口右缘。
- **为什么不复现 R2-11 当年的拥挤**：当年单条塞 8 项（含壳内导入按钮 + 〈 全部项目）；现在左簇是 logo + 返回（带文字）+ 名称三项——`[导入整部剧本]` 留在制作页页头动作位（R2-11 裁定不动，§4.2）、`〈 全部项目` 由 logo 兼任、品牌文字排换纯 logo 标；返回文字虽常显，但 `text-xs` 辅助档、随名称区共享 `truncate` 余量。实施时需在 1280 / 1440 两档宽度核长剧名与长镜名截断（`truncate`）。

> **线框口径（2026-08-17 修订）**：本文 §4 每页线框顶部一律画**壳单条**（本节上图），各页按所在位置标注 `制作/资产` 的 ●/○/✓ 与 `⚙`；项目列表页线框只画 `logo 标 + 精简版 + 用户名`。窄线框里壳文案按可用宽度压缩（如 `‹ 返回`、`⚙ 配置`），完整写法以本节为准。内层容器 = `mx-auto w-full max-w-[1440px] 2xl:max-w-[1920px] px-4`，与 §3.1 内容容器同宽同内边距，两端精确对齐。

| 分镜卡封面 | `aspect-video rounded-md bg-surface-2`（视频首帧预览 16:9，`object-cover` 裁切；竖版资产图仍用上行 9:16） |
| 变体卡（缩略） | `aspect-square rounded-md bg-surface-2` 上图下名；无版本图显类型图标占位不塌陷；`＋ 新建变体` 为同规格虚线引导卡（`border-dashed`） |
| 卡标题 | `text-section-title text-ink-1 line-clamp-1` |
| 卡描述 | `text-body text-ink-3 line-clamp-2`（固定 2 行，卡高度稳定） |
| 徽记 | Badge `tone`（`character/scene/…` 类型色；状态用文字+色点，不堆徽记） |

**尺寸规则（卡面/内容区宽高统一）：**

- **网格列数**：列表页卡片一律 `grid grid-cols-2 gap-4 md:grid-cols-3 lg:grid-cols-4`，不再用不定的 `flex wrap` 撑宽。
- **卡宽**：跟随网格列自适应（`minmax(0,1fr)`），不写死像素宽；卡内元素 `w-full`。
- **卡高**：由「图片区固定 aspect + 文字区固定行数（标题 1 行 + 描述 2 行）」决定，不依赖内容长短跳高。
- **详情页左右比例**：资产详情/分镜详情统一 `2:3`（左窄右宽），右栏 `minmax(0,1fr)` 防溢出。
- 间距全用 4px 网格（`gap-4`），圆角走 §3 圆角 token（卡片 `rounded-lg` 14px，浮空层 `rounded-xl` 16px；与 `primitives.tsx` Card 原语、`dialog.tsx` 弹窗同源）。

### 3.4 弹窗尺寸档（Dialog 四档，锁死组件既有档位）

`dialog.tsx` 已有四档，Lite 弹窗一律从档位选，**禁止 `max-w-*` 裸覆盖**（现状 `新建资产/加图` 的 `max-w-3xl` 绕过档位，改 `size="wide"`）：

| 档 | 用法 | 最大宽 | Lite 用途 |
|---|---|---|---|
| `small` | 确认类 | `max-w-sm`（24rem） | 放弃解析 / 重新生成 / 删集 / 整剧覆盖 |
| `medium` | 单表单元 | `max-w-lg`（32rem） | 新建/编辑项目 |
| `large` | 中等工作台 | `max-w-2xl`（42rem） | 加参考素材 |
| `wide` | 复杂工作台 | `max-w-5xl`（64rem） | 新建资产 / 加图 / 候选图 |

- 结构固定：`DialogHeader`（标题+说明）→ `DialogBody`（滚动）→ `DialogFooter`（右对齐动作）。
- 统一 `max-h-[85dvh]`、`rounded-xl`、`border-border-2`（组件内置，不逐处改）。
- **付费动作弹窗 footer 必须带任务次数明示**（「N 次任务」/「生成 1 张」），见 §5.3。

### 3.5 页内 tab（仅素材页用）

- 素材页的资产类型条（`全部/角色/场景/道具/服装/音频/光线/摄影/视频`）保留，但它是**页内分类 tab**，与壳导航无关。
- 页内 tab 状态持久化到 URL query（现状 `asset_tab` 已是此模式），**不用 localStorage**。
- 规则：**壳是工作页导航（制作/资产），页内 tab 是单页内容分类**，两层职责不同；任何页面**不得超过一层页内 tab**。唯一受控例外是配置页（§4.6）：媒体类型 tab（图/视频，页级分类）+ 模板 tab（`[系统默认][自建…][+ 新建模板]`，是**单选生效控件**的 tab 呈现，不算内容分类层），两层职责清晰，媒体类型 tab 持久化 `?kind=`。

### 3.6 状态三件套（loading / empty / error）

每页必须三态齐全，统一组件：

- **loading**：`Skeleton` 网格（卡片数 = 可见区域可容纳数量），不带文字。
- **empty**：`EmptyState` 三要素——**这是什么 / 为什么空 / 下一步动作**（如「还没有资产。先回制作页一键生成本集，或点右上角新建资产。」）。
- **error**：`ErrorState`（错误人话 + `重试` 按钮），错误文案走 `humanErrorMessage`，不吐原始接口错误。

> 三态是**通用组件**；空项目的**具体首跑原型**见 §4.7（项目列表空 / 制作页首跑 / 集级空 / 素材空 / 分镜区空）。

### 3.7 高度模型（内容随页面滚 或 视口固定分栏）

> 回答「所有页面是否都要固定适配屏幕高度」：**不是。** 全站只有两种滚动模式，由页面语义决定，不是逐页自选。新增页面先按 §3.7 判定，不许凭感觉挑。

**模式 A —— 内容随页面滚（默认，绝大多数页）**

- 整页一个滚动容器（§3.1 外层），内部各块**自然堆叠、随页面共同滚动**。
- 适用：列表页、表单页、设置页——内容是一串**互相独立的竖排块**（卡片网格 / 表单卡），没有「一栏驱动另一栏」的同屏参照需求。
- **页内不设子滚动区**：不出现「卡内滚动 + 页面滚动」的双滚动条；内容再长也是把页面撑高、整页滚。

**模式 B —— 视口固定分栏工作台（唯一例外，仅工作台页）**

- 页面 = 视口可用高（`h-[calc(100dvh-壳高-间距)]`），左右/上下栏 `overflow-y-auto` **各自独立纵向滚动**，栏内再细分滚动层（如制作页右栏仅分镜区滚、分镜详情右栏版本条横滚 + 提示词竖滚）。
- 适用且仅适用三个工作台页：制作页（§4.2）、分镜详情（§4.3）、资产详情（§4.4.2）。
- **B′ 例外（R2-8，2026-08-14 二次裁定）**：配置页 `/config` 不满足「左右分栏工作台」判定，但按用户裁定宽度/高度与工作页对齐——固定视口高、不做整区滚动层、模板内容 Textarea 内部滚（详见下方配置页小节与 R2-8 条目）。
- **判定规则（三条同时满足才用 B，否则一律 A）：**
  1. **左右两栏内容互相关联**——一栏的选择驱动另一栏的展示/操作（左选集→右栏整栏刷新、左选分镜→右栏版本与参数、左选变体→右栏信息与版本轨），需要同屏参照；
  2. **是「工作台」不是「设置/浏览」**——栏内是当前工作主体 + 即时反馈（出片/定稿），不是静态内容陈列；
  3. **一屏内高频往返**——换集→看剧本→出分镜、选镜→出片→定成片，来回切换是主操作路径。

**全页面模式表：**

| 页面 | 模式 | 滚动区 |
|---|---|---|
| 项目列表 `/lite` | A 内容随页面滚 | 整页 |
| 制作页 `/workspace` | B 视口固定分栏 | 左栏整栏滚；右栏仅分镜区滚（§4.2） |
| 素材页 `/assets` | A 内容随页面滚 | 整页 |
| 资产详情 `/assets/:id` | B 视口固定分栏 | 左右两栏各自滚（§4.4.2） |
| 分镜详情 `/shots/:id` | B 视口固定分栏 | 左栏整栏滚；右栏版本条横滚 + 提示词竖滚（§4.3） |
| 配置页 `/config` | B′ 固定视口高（单列表单，非分栏） | 无整区滚动；模板配置文本框内部滚（R2-8 二次裁定） |

**配置页的高度模型（R2-8 二次裁定，2026-08-14）**：配置是**设置类表单**，不是分栏工作台——不套用模式 B 的左右分栏与栏内滚动，但高度按用户裁定固定为屏幕可用高（容器与制作/分镜/资产详情同公式 `h-[calc(100dvh-…)]`）：

- `[图片配置][视频配置]` 两卡是**各自独立的表单**（各带底部保存按钮），互不驱动，没有「一栏选择刷新另一栏」的耦合；
- 模板库 tab 面板是**卡内内联面板**：新建/编辑/复制新建共用面板，编辑器增高卡（标题随模式、内容 ≤5000 字、字数计数）；
- **不做整区滚动层（用户二次裁定「只有模板配置的文本框内部滚动就行」）**：页面与内容区都不设滚动容器，内容自然排布；模板内容 Textarea（rows=4）在框内滚动，长模板不会撑起页面滚动；
- 两卡常驻挂载、切换不丢未保存编辑，切换只切 `hidden` 可见性，固定高容器内单卡展示、互不挤压。

- **集可拖动排序（R2-13，2026-08-17 二轮修订）**：左栏「剧集」头纯文字 `拖拽/完成` 开关（无图标）；开启后集项可拖（改名态禁拖），拖起半透明、悬停目标 accent 描边；落下 = 被拖集移到目标位置，`updateEpisode({ sort_order })` 落盘，失败重拉回滚；显示顺序 = `sort_order` 优先、集号次之。拖动只改展示顺序，不改 `episode_no` 与分镜编号。
- **集名可改**：左栏集项 hover 出现 ✏，行内改名（`updateEpisode({ name })`，失焦自动保存，同剧本正文保存模式）。
- **集可删**：集项 `⋯` 菜单 →「删除本集」（沿用完整版 `lite-script-page` 已有删除弹窗与软删语义：该集分镜与素材一并隐藏、回收站可恢复，不硬删，R1 合规）。
- **右栏状态机**（现状 `lite-script-page.tsx` 五态保留，只挪位置）：
  - `paste`：内容区 = 粘贴卡（文本框 ≤60000 字，无文件导入按钮），动作条 `[一键生成本集（1 次任务）]`。
  - `processing`：动作条 loading「正在解析…」；分镜区 = 骨架；原文保留在内容区只读。
  - `review`：**分镜候选表占据分镜滚动区**（集/场/镜/画面/台词），动作条变 `[采用草稿]` / `[重来]`；资产候选显示在资产引用条的「候选待确认」态。
  - `confirmed`：内容区 = 已确认摘要（锁定）+ `[编辑剧本]`；动作条 `[重新生成本集]`；分镜区 = 正式分镜卡片网格。
  - `failed`：人话原因（`humanErrorMessage`）+ `[修改后重新生成]`，原文回填文本框。
- **分镜卡规格**（现状 `lite-shots-page.tsx` 已实现，本文定稿）：
  - **固定高度**：卡高 = 封面区（`aspect-video` 定高）+ 文字区固定行数（镜码/名称行 1 行 + 画面描述 `line-clamp-2` 2 行 + 状态/保存行 1 行）；封面缺失有占位（`暂无画面`）不塌陷，卡片高度恒定。
  - **封面默认 = 默认视频版本的首帧**：`video preload="metadata"` 由浏览器抓首帧展示；优先级 = 人为已定首帧图 → 默认视频版本首帧（现状取该镜最新一条视频）→ 占位；`object-cover` 裁切适配卡位。
  - **命名 = `{集号}-{镜号}-{场景短名}`**（自动生成，如 `01-003-外景`）；**分镜名称可编辑**：卡片名称行（`shot.title`）行内编辑、失焦自动保存（`updateShot({ title })`，同画面描述保存模式）；场景短名随 `scene.name` 变化，改场景名即更新镜码后缀。
- **成品交付（分镜卡段⑤）**：卡片只做**成片收纳**——看片 / 定成片 / 下载 / 失败原因展示（现状已实现，`LiteShotVideos`），不离开分镜区，不需要独立「成片」页。**卡片上不放任何出图/出片按钮（无卡级生成）**：生成唯一入口在分镜详情工作台（§4.3，付费动作一次点击一次任务、明示次数）；已出片镜在卡上以 `●已出片 N` 徽记 + 段⑤视频条收纳，未出片镜给引导文案「挑一张定下来，或者直接带参考出片」（点卡片进详情）。集级交片 = 分镜区头次级动作「打包本集成片」（见下）。
- **集级打包**（新，替代被删的下载页）：分镜区头次级动作「打包本集成片」→ 收集当前 `?ep=` 下所有**已定稿**视频 → 逐个或整包下载。服务端过滤持久化（persisted）才可下载（复用 `mediaDownloadable` 闸门，不另抄判定）。这是**集级**交片入口，和每镜下载互补，不做项目级总览页。
- **删除分镜**：软删 + 确认弹窗（同集删除的软删语义，回收站可恢复，R1 合规）。
- **分镜详情页**（独立路由 `/lite/projects/:id/shots/:shotId`）：完整线框与交互规格见 **§4.3**（本文件重设计的左右分栏工作台，与资产详情共用左右分栏设计语言）。
- 弹窗：一键生成/重跑确认（§4.2.1）、导入（§4.2.2）。

│  ◉ 整条重新做                              │
│     照同样要求重新生成一整条,              │
│     得到新版本 v4(不覆盖这个版本)          │
│  ○ 只改某几秒                              │
│     切成几段,只重做不满意的那段,           │

└────────────────────────────────────────────┘

**三个选项对应技术模型**（与 `lite-shots-page.md` 一致）：

- **整条重新做** = 基础重做（流程 4a）：以这个版本为参考重新生成一整条，得到新版本 v4，**不覆盖 v3**（每条视频是独立 `media_results` 行）。想「从第 N 秒起重做」也在这里：先在播放器上把进度拖到第 N 秒，选「以第 N 秒画面为开头重新做」——新视频前 N 秒视觉上对得上 v3，后面重新生成。**诚实命名**：生成的是整条新视频，不是拼接。
- **只改某几秒** = 片段编辑（流程 4b）：〔下一步〕进片段编辑视图（实现顺序在后，`lite-shots-page.md`），只重做不满意的段，其余原样保留。
- **删掉这个版本** = 软删（`media_results.deleted_at`），不硬删；当前版需先换成别的版本才能删。

**编辑什么**：版本名 = 版本标签（存 `metadata.shot_version.label`，走 `PATCH /shots/:shot_id/media/:media_id/version-label`）；备注 = `metadata.shot_version.note`。改版本名只是语义备注，不改版本编码 `-v3`（编码查询时按 `created_at` 算，永远不变）。

## 5. 交互逻辑（跨页约定）

### 5.1 集全局跟随（`?ep=`）

- 制作页内 剧本/资产引用/分镜 共享当前集语义；左栏切集 = 更新 URL `?ep=`，右栏全部内容重载（现状 `readCurrentEpisodeId` 模式保留）。
- 资产页不跟集（资产是项目级），但资产详情的「出现记录」可展示集的归属。
- 失效集号（集被删/未生成）→ 回落最近可用集，URL 同步修正，不弹错。

### 5.2 页内 tab 持久化（仅素材页）

- 素材页 `asset_tab` → URL query 持久化，**禁用 localStorage**（刷新与分享即对，现状已如此）。
- 壳工作页 = 路由，天然可分享。

### 5.3 付费红线在界面上的表达（§4 铁律）

- **一次点击一次任务**：出图/出片/生成按钮点击即创建且仅创建一次任务；不提供批量/全选/自动重试按钮。
- **付费动作明示次数**：凡创建任务的确认弹窗/按钮，必带「N 次任务」或「生成 1 张」字样。
- **失败不自动重试**：失败卡给人话原因 + 手动「重试」按钮；不自动提交、不夜间批量。
- 服务端预算/幂等/权限检查为最终裁决，界面提示只是前置引导。

### 5.4 任务状态机（全站统一展示）

```
pending ──→ running ──→ succeeded（→ 可下载/定成片）
              │            │
              └────→ failed（人话原因 + 手动重试）
              └────→ timeout（提示 + 可刷新状态）
```

- 轮询：3s 起，指数退避至 30s 封顶；刷新页面恢复状态，不丢。
- 幂等：提交用 `newId` 生成 request id（现状 `lite-review` 语义），重复提交去重。
- 状态展示：文字 + 状态色点；不堆徽记（§3.3）。

### 5.5 工作页完成态（壳）

- `制作 ✓`：当前 `?ep=` 集剧本已确认（confirmed）且有分镜；未确认 = ○。
- `资产 ✓`：项目已存在 ≥1 个资产实体（或有资产候选待采用）。
- 完成态只影响**视觉标记**（✓/●/○），**不锁跳转**：创作是反复的，随时可回任何页。

### 5.6 导航与权限

- Lite 路径不设前端权限分层；无权限动作后端如实返回错误 → `humanErrorMessage` 呈现（R3：Lite 路径是一等公民，任何 zod/字段改动必须走通本路径）。
- Esc 行为：详情页 Esc 返回上一级；lightbox 开着时由 lightbox 优先处理（现状已实现）。
