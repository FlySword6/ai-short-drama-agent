# 拆书定妆合同(v0.3.0,#27,2026-07-23 起草)

背景:版本计划 0.3.0 卡(DC 7-23 拍板):AI 读剧本提资产清单→追问补全→
每资产多版候选→选定入库。设计输入:台账条 9(反同脸三层框架)、条 24/25
(LuxReal 角色×造型+三视图)、条 31(抽象参考四件套)、条 32-7③(丽芬
角色板三机制)、条 32-9(provider 分类)。遵守 platform-ontology.md、
ai-foundation-gateway.md(agent 层首件)与防复刻纪律(条 30)。

## 一、资产模型:角色×造型二级结构(升格既有 variant)

- **角色板 = 唯一身份 + 多造型变体 + 版本**(丽芬 32-7③ 用户侧印证:
  "角色详情不该新建人设"):角色资产承载身份锚(骨相/体貌/年龄段/气质),
  **造型**(常服/战损/囚服…)继承身份、差异只在服装与状态(LuxReal 条 24);
  生成引用到**具体造型**,不引用裸角色。
- **三机制照抄丽芬**(条 32-7③):①锁定(锁身份/锁造型,锁定后改动走
  新版本);②引用追踪(被 N 个控制包/任务引用,改动提示重检——本体 R8);
  ③临时状态沉淀为资产(生成中间态可一键转正式造型)。
- **定妆产出标准**:每造型候选=三视图定妆组(正面特写+全身正/侧/背,
  条 25),可选单图快档;定妆图即该造型的默认参考集。

## 二、拆书 agent(AI 底座 agent 层首件,#28 演进锚兑现)

- 流程:剧本(结构化 IR,#24)→ **提资产清单**(角色/场景/道具/服装,
  按出场频次与剧情权重排序)→ **grill 追问**(见下)→ 每资产 N 版候选
  (走生成主链,批量=batch-submit 合同)→ 用户选定 → 入库(角色×造型)。
- **grill 问题集三层结构**(条 9 反同脸框架为骨架,服务端模板,R7 不回显):
  ①骨相先行(脸型/五官结构/体态——身份层,锁定后不再问);
  ②肌理肤色绑人设(质感/年龄痕迹/肤色——身份层);
  ③妆造定氛围(发型/服装/配饰——造型层,每造型重问)。
  预设加速:五类古装男性等**角色分类预设**(条 9)+丽芬题材分类联动。
- **系统级默认负面词**:idol face/V-jaw/porcelain skin/same-face 等反同脸
  avoid 约束(条 9)+AI 生成感/塑料磨皮/CGI 感/动漫插画风(条 31 截图)
  合并为全局负面词库,服务端注入五层组装的负面层,用户不可见不可改
  (项目级可叠加自定义负面集,条 31 四件套之一)。
- agent 纪律(#28):产物走确认卡,不自动扣钱;每次 LLM 调用过网关落
  ai_calls;候选≠成员(生成的定妆图=候选,选定才入库)。

## 三、抽象参考四件套升格(条 31,随本合同落对象模型)

资产六类外补全抽象参考族(参考快照 v2 的 lane 体系加位):
1. **色卡**(结构化对象:分区块服装色/环境色/光影色/锚点色,每色
   hex+名字+使用规则;双通道注入=渲染色卡参考图给模型读像素+hex 写进
   提示词文本);
2. **光影方案**(时刻/光质/方向/氛围);
3. **摄影方案**(胶片质感/LUT/镜头/颗粒);
4. **负面约束集**(系统级+项目级叠加)。
继承模型:抽象参考天然项目级/集级默认(全片一个味),分镜级可覆盖;
提示词分层组装(画面元素→光照→色彩→摄影质感→负面)**全在服务端**。

## 四、自定义 provider(0.3.0,网关管理端,合同要点)

- provider 表+格式适配器(预置 Ark/OpenAI 兼容/Gemini 模板)+key 进
  服务端密管(KMS);入口只在管理员面(丽芬 32-9,费用走平台积分红线);
- provider 分类五维(丽芬参考图):语言/视觉理解/图像生成/视频生成/
  语音合成;
- 接能力档:自定义 provider 的模型也必须走"实测→建档→上架"解锁流程,
  不给档外直调。

## 五、验收口径

1. 拆书链真栈:上传剧本→资产清单(可增删)→grill 三层追问(骨相问题
   只在新角色出现)→批量候选(确认卡示总价)→选定入库为「角色×造型」;
2. 角色板:同角色加造型不产生新身份;锁定后生成引用旧版本快照;引用
   追踪计数真实(改锁定资产弹重检提示);
3. 负面词纪律:抓包/日志验证提示词含系统负面层,前端源码零负面词表(R7);
4. 三视图:定妆组四图入库为同版本组,可整组设为造型默认参考。

## 六、边界

- 配音/音色绑定归声音工坊(sound-workshop.md);剧本 IR 解析归 #24;
- 拆书报告(钩子/转折/情绪评估)是 0.3.x 剧本工坊的事,本合同只提资产;
- 本合同不定 UI 细节,Kimi 包发出时随 goal 附丽芬角色板参考图。
