# 模型、Pi 与付费任务合同

## 统一模型能力

业务层只识别能力，不识别供应商特有字段：

- 图片：文生图、参考图生成、故事板、角色板、局部修改。
- 视频：文本/图片/多模态全能参考生成。
- 音频：预留语音、音效和音乐能力，本版本不要求完整生产链。

V0.1.1 目标适配 GPT Image 2、Gemini 图像模型、Seedream 5 Pro、Seedance 2.0、HappyHorse 1.1。产品名称与供应商实际 model ID 分离；只有真实查询供应商后才能把 ID 标记为可用。Seedance 2.5 的 30–180 秒能力进入后续路线，不是本版本上线前置。

## 适配器输出

每个适配器必须返回统一内容：供应商任务 ID、标准状态、输出媒体、可重试性、原始错误摘要、实际模型 ID、参数快照、用量和费用记录。原始响应仅在受控日志或调试表中保存，不直接进入页面。

## 人工提交

1. 人选择分镜或导演台上下文。
2. Pi/系统生成结构化提示词草稿、参考素材、模型和参数建议。
3. 页面展示即将使用的关键内容；用户可修改。
4. 用户点击“生成”或等价主按钮。
5. 服务端再次检查登录、权限、参考通用资产当前审核态、预算、幂等和模型可用性，只创建一个任务。
6. 长任务后台运行；需要人决定时进入判定收件箱。

禁止 Pi 自动执行第 4 步。禁止自动重试付费任务；失败后由人点击重试，系统可以复用原参数并提示原因。
报价冻结的是费用与展示快照，不冻结资产使用权；建单、人工重试和 Worker 发起供应商请求前
必须重查通用资产仍为 `approved`。未过审返回 `422 control_asset_invalid_usage` 中文错误，
且不得触发供应商调用；个人资产免审但仍须满足所有者或项目精确引用权限。
点名 422 只返回给平台管理员或已持有该精确项目素材引用的成员；仅凭 UUID 探测未公开
待审通用资产时返回通用 403，不公开资产名称、状态或详情。

## Pi Agent Core

Pi 运行在后端，工具必须使用现有 application service。首批工具：

- 搜索、筛选和加入资产；
- 读取项目、分镜、任务和版本状态；
- 读取和操作 3D 导演台的安全动作；
- 准备图片/视频生成草稿；
- 创建待人工提交的生成意图；
- 整理失败、待判定和下一步建议。

工具按读、可恢复写、付费/高风险分级。每次调用记录会话、用户、项目、工具、参数摘要、结果和耗时。Pi 不得伪造成功，不得在工具失败后用自然语言声称完成。

## 成本控制

- 前台保持心流，不强制逐次查看估价。
- 后台按用户、项目、模型和月份记账并执行预算上限。
- 高成本、长视频和批量操作可以要求额外确认，但不能把供应商价格细节堆到主工作台。
- 测试默认使用假适配器和零付费合同测试；真实调用必须有明确授权和预算。
