# 场次与镜头边界 · 标注口径(scene-shot/v1)

这一维度只回答三个问题:**这一集分成几场?每场大致哪几句话?每场该切成几个镜头?**
判断依据是**时空是否变化**(决定场)和**机位是否必须变**(决定镜)。

角色/资产/连续性这些维度不在本文件范围内,由其他 lens 的金标负责。

---

## 一、场怎么切

| 规则 | 说明 |
|---|---|
| `S1_SLUGLINE` | 遇到场次标记行(`INT.` / `EXT.` / `I/E.` 开头)就开新场。 |
| `S2_NO_IMPLICIT_SPLIT` | 没有标记行的地方一律不新开场,哪怕场内有人进出、有时间流逝。 |
| `S3_TRANSITION_BELONGS_TO_OUTGOING` | 转场行(`CUT TO BLACK.` / `BACK TO PRESENT:`)归上一场收尾,不单算场也不单算镜。 |
| `S4_GROUP` | 闪回、交叉剪辑、蒙太奇用 `group` 字段标出来,但**不改变场的条数**。 |

场这一层基本是确定性的:22 条场次标记行 → 22 场,和 `facts.json` 的 `scene_heading_lines`
逐条对齐,生成脚本会强制校验,对不上就不出文件。

**同名标记行不合并。** idb EP1 的仓库地下室出现两次(L1、L79),客厅也出现两次(L53、L103),
按标记行算就是四场。理由:客厅那两次中间隔了七天(L105 的 SUPER 明写),
若按"同地点合并"就会把它们错并成一场。同一套规则要在全集内自洽,所以一律不合并。
交叉剪辑的读法分歧留在各集的 `disputed` 里。

## 二、镜怎么切

原则:算的是**「最少必须切几次机位」**,不是导演的分镜偏好。
每一镜都必须能说出是哪条规则逼出来的,写在 `cutTrigger` 字段里。

### 会切一镜

| 规则 | 说明 |
|---|---|
| `NEW_SCENE` | 每场的第一镜。 |
| `SPEAKER` | 说话人换了。一个角色名下的连续台词算一镜。 |
| `REACTION` | 正文点名了不说话的人的反应("Charlotte stands frozen"、"The crowd erupts")。 |
| `INSERT` | 有一件东西必须看清(来电显示、照片、匕首、拉链、血迹),大景里看不清。 |
| `SPATIAL_MOVE` | 有人进画、出画,或移到场内另一处,机位必须重新找。 |
| `SCALE_CHANGE` | 一个节拍需要明显不同的景别才成立(耳光、踢击、锤子落下、变身完成)。 |
| `VFX` | 正文写了 `VFX:` 的视觉特效节拍。 |
| `VO_BLOCK` | 旁白/画外独白自成一段、没有伴随动作时,单独一镜(通常是一个持续画面)。 |
| `ACTION_BEAT` | 独立的动作节拍,不属于上面任何一类时的兜底。 |

### 不会切一镜

| 规则 | 说明 |
|---|---|
| `CONTD_MERGE` | 紧挨着的同一个人的 `(CONT'D)` 续说,中间没有动作,并成一镜。 |
| `MERGE_PREBEAT` | 某个动作段只是紧接着开口的那个人的准备/反应,且机位不变,并进他那一镜。 |
| `OS_VOICE` | 画外音说话人换了,但画面留在听的人身上,不切。 |
| — | 括号提示(表演提示)。 |
| — | 只有声音没有画面的 `SFX:` 行。 |
| — | 对上一句的修辞性补充(如 "Pure, lethal sex appeal.")。 |
| — | 转场行、`SUPER:` 字幕(叠在所在镜头上)。 |

## 三、证据契约

每一镜带:
- `lineStart` / `lineEnd` —— `.txt` 里 1 起的行号
- `evidence` —— 正文原样片段

生成脚本(`scripts/eval/breakdown/build_scene_gold.py`)在出文件前逐条回查:

1. 引文必须在声明的行范围里真实存在;
2. 镜头顺序必须与正文的字符顺序一致(用引文的绝对偏移做单调性检查);
3. 场内每一行非空正文都必须被某个镜头覆盖(标记行除外);
4. 场次标记行必须与 `facts.json` 完全一致。

任一条不过就**不写出任何文件**。跑 `build_scene_gold.py check` 可以随时重验。

**允许多个镜头共用一个行号。** idb 是 PDF 硬折行,一个"段落"里常含 3-5 个节拍
(例如 EP1 L41 一行里有:她窒息 / 手机响 / 她挣绳 / 他捡起手机 / 来电显示特写 / 他冷笑),
靠 `evidence` 区分先后。

## 四、这份金标的效力边界

**状态:`single-annotator-draft`。一份标注就是一个人的读法,单份不构成最终真值。**

- **场边界这一层**争议小,有场次标记行兜底,可以直接用。
- **镜头数这一层**是判断,必须再来至少一份独立标注做裁定,分歧留档后才配当真值。

标注员是模型(claude-opus-5),不是人类。它的独立性体现在:**全程只读逐集 `.txt` 正文,
未调用平台拆解功能,未看过任何模型拆解输出**——所以它不是被测对象的复印件。
但它仍然是一份 LLM 读法,和"人工水准"之间的差距需要靠第二标注员和裁定来补。

## 五、评分建议

- **两层分开算。** 场边界和镜头数别混成一个分数。
- **场边界**按 `headingLine` 集合算精确率/召回率。
- **镜头**别用数量精确相等判对错。建议:
  - 用行号区间重叠(IoU ≥ 0.5)做匹配后算精确率/召回率 —— 衡量切得**准不准**;
  - 另报一个粒度比值 `系统镜数 / 标注镜数` —— 衡量**碎不碎**。
- **`counts.elementCount` 不是上下界。** 它是版式算出的段落级元素数,当第三条参照线用。
  实测两个方向都会被穿透:idb 人工镜数高于它(硬折行要拆开),
  bdlw 人工镜数低于它(作者段落碎,预备动作要并)。
- **`group: montage` 的场**(bdlw EP7 S2 追逐段)镜数本来就可长可短,建议只判场边界不判镜数。
- **`disputed` 里的条目**两种读法都判对,或整条排除;不要单选一种当唯一正确答案。
- **每集单独算再看分布。** 集长差 4.7 倍,只报一个平均值会被长集主导。
- **两部剧分开看。** idb 的动作元素数被 PDF 折行压低了,别跨剧本直接比镜头密度绝对值。
