# 安全与凭据处理

## 凭据

- 模型、TOS、数据库、企业微信和登录凭据只存放在本地忽略文件或部署平台密钥管理中。
- 仓库只保留变量名和无效示例值。示例值不能与真实账号、域名私有路径或生产资源对应。
- 前端永远不能获得供应商密钥；所有外部调用经过后端适配器。

## 权限

- 所有公网入口强制登录。
- 服务端根据账号、角色、项目成员关系和动作做权限判断；隐藏按钮不能代替服务端鉴权。
- 人是责任主体：AI 可以自动处理，但不能自行更换责任人、批准交付、改变预算或发布内容。

## 数据与日志

- 日志允许记录任务 ID、模型别名、状态和耗时，不记录原始密钥、完整用户输入、未脱敏供应商响应或私有媒体 URL。
- TOS 私有对象通过短期签名地址访问；正式事实和权限保存在 PostgreSQL。
- 上传内容必须校验类型、大小和来源；远程下载必须防止访问内网地址。

## 泄露处理

发现疑似凭据泄露时：停止使用相关凭据，轮换并吊销旧值，检查 git 历史和运行日志，再用 gitleaks 等工具复查。不要只删除当前文件就视为处理完成。

安全问题请私下通知项目负责人，不要在公开 issue 中粘贴凭据或敏感请求响应。
