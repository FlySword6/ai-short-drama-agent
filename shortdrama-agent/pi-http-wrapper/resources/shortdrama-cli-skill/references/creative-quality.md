# 创作质量门

只在用户要求创作、润色、拆分或生成 prompt 时读取本页。普通 CLI 搬运任务应保留用户原意，不主动扩写。

## 剧本到分镜

1. 先识别叙事单位、场景空间、连续动作和情绪转折。
2. 新镜头必须带来新信息；地点、时间或核心互动对象发生实质变化时切镜。
3. 连续动作链优先保持连贯，避免把一个动作拆成无意义碎镜。
4. 每镜明确主体、场景、核心动作、台词、景别/机位、运镜、光影和环境动态。
5. 原始台词逐字保留；除非用户明确要求改写，不翻译、不增删。

## 图片提示词

- 固定人物身份、外貌锚点、服装、道具和场景锚点；引用已有 asset ID/URL，而不是重新描述成另一角色。
- 描述可见画面与构图，避免抽象文学词代替可执行视觉信息。
- 明确画幅和用途；竖屏短剧通常由项目或用户指定 9:16，不擅自覆盖。
- 负向约束只写与任务相关的缺陷，不堆砌通用“8K/大师级”词。

## 视频提示词

建议按以下顺序组织：

```text
主体与身份锚点；场景与时间；起始状态；核心动作与节奏；
镜头景别、机位和运动；光影与色调；环境动态；台词/声音；
连续性与禁止项。
```

- 单镜动作量匹配时长，不在 5 秒内塞入多个复杂转场。
- 运镜服务叙事：高能段落可快切、甩镜、快速推进；情感段落可慢推、静态凝视、长焦压缩。
- 明确“不要生成字幕”只在交付确实不需要画面内字幕时使用。
- 多参考输入要说明每个参考的角色：首帧、角色、场景、服装或道具。

## 剪辑与交付

- 先保证空间、动作、视线和声音连续，再追求炫技转场。
- 用 J-cut/L-cut 维持节奏和情绪连贯；声画切点应有叙事作用。
- 核对镜头时长总和、对白可读时长、画幅、帧率、字幕安全区和音频峰值。
- 导出前确认所有引用资产、镜头顺序、字幕版本与结果采纳状态。

## 连贯性检查

每次批量生成前核对：

- 同一人物的脸、发型、年龄、服装与饰品；
- 场景布局、时间、天气与主光方向；
- 道具的外观、持有者和前后位置；
- 动作起止姿态、视线方向和轴线；
- 台词顺序、说话者与口型/音轨关系。
