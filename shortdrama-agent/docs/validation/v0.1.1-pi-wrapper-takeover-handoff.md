## 给主仓 provider 的冻结合同

详见 `docs/contracts/v0.1.1/pi-http-wrapper-takeover.md`。集成红线：

- 接在主仓 `Agent.streamFn`，业务工具仍在主仓本地执行；
- 工具执行结果成功落 `agent_messages` 后，才向 wrapper 发送 `toolResult`；
- 401/403/409/422/协议错不降级；网络/503 仅在首个业务可见事件前允许整轮切 Ark；
- 不新建第二审计表，不让 wrapper 直接访问主仓数据库；
- wrapper usage 未知时，主仓必须保留未知，不能转为 0。
