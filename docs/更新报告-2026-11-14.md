## 本地迁移与启动

1. 在新 monorepo 执行 `npm run setup` 和 `npm run build`，构建成功。
2. 启动原 PostgreSQL 17 数据卷 `shortdrama-agent-lab_postgres_data`，迁移前保存私有 `pg_dump` 备份：`packages/main/outputs/private/story-studio-before-v0.2.dump`。
3. 原数据库 001–016 迁移账本在 Windows 环境记了 CRLF 哈希；逐项确认全部与当前迁移文件仅换行字节不同后，在事务中把这 16 个账本哈希校正为 LF。随后应用 017–031 共 15 项新迁移，未重建或清空业务库。
4. 复制本地 `.env`、模型连接文件和旧媒体目录到 `packages/main/` 的对应私有路径。没有读取或输出密钥值；未把这些文件加入 Git。
5. 后端以开发兼容的 `LYRA_RUNTIME_ROLE=all` 模式运行，前端由 Vite 运行。访问 [Story Studio 首页](http://127.0.0.1:5173/#/studio)；后端 [存活检查](http://127.0.0.1:8788/livez) 和 [就绪检查](http://127.0.0.1:8788/readyz) 均返回 HTTP 200。

本机只启动了 PostgreSQL、单进程后端和前端。Stage 1 部署文档中的 Redis、Milvus、MinIO、多容器 API/Worker 拓扑没有在本次本机开发模式中启动或验收。没有提交任何真实付费模型、Embedding、生图或视频任务。
